🎵 Spotify Clone
A simple Spotify clone built using HTML, CSS, and JavaScript, with local storage for storing songs.

🚀 Features
✅ Play, pause, and skip songs
✅ Custom audio player with controls
✅ Display current song details
✅ Local storage for song data persistence
✅ Responsive design

🛠️ Tech Stack
Frontend: HTML, CSS, JavaScript

Storage: Local Storage

📂 Installation & Usage
Clone the repository:
git clone https://github.com/yourusername/spotify-clone.git
cd spotify-clone
Open index.html in a browser.
